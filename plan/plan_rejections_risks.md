# 🧨 ACTION-ATLAS: Novelty Reality + Rejection Risks (single file)

> 🎯 Zero-shot ROBOTIC-EXECUTION-ONLY, 3 acting families (⚡ VLA vs 🧠 LWM / 🎬 WAM; 🌌 WFM = video-only reference). Cold reality (web-verified 2026-08): no standalone novelty left, every wedge scooped (Table 1); honest frame = WAS assessment crediting priors + a 3-model DROID/Franka reproduction; core rule = assess WAS, do not adopt it.
